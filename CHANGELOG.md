# Changelog

## 0.1.0 — 2026-08-26

- Initial public case-study release of Opportunity Engine.
- Multi-source collection (mock, JSON, RSS, HTML, optional Playwright).
- Raw provenance, normalisation, validation, deduplication and change detection.
- Deterministic scoring and deadline urgency.
- Excel / CSV / JSON reporting, console notifications, FastAPI and dashboard.
- Prefect 3 wrapper, Docker Compose, CI and documentation.
